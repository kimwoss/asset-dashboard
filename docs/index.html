• 금융자산·부동산은 매일 자동 기록됩니다 — ★월별자산 이번 달 칸에 주식계좌 평가액과 부동산 KB 실시세가 매일 최신화되어, 달이 바뀌면 말일 값이 자동 확정됩니다. (부동산은 이제 웹과 같은 KB 실시세를 씁니다)
