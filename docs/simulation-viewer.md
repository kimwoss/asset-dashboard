# 하단 시뮬레이션 보기

로그인 후 모든 탭 하단에서 접었다 펴는 읽기 전용 전망 패널을 제공합니다. 기존 시뮬레이션 수집·복호화 경로를 사용하며 시트 계산값을 그대로 표시합니다. 별도 계산기는 추가하지 않습니다.

- 연도 선택: 명목/실질 순자산, 연간 지출(생활비+보험료·의료비), 연간 유입(연금+은퇴후소득). 저축은 유입 합계에서 제외합니다.
- 기존 실질/명목 차트와 연도별 표를 패널로 이동했습니다. 마지막 나이 표시는 원자료의 마지막 행을 따릅니다.
- 원본 시트 링크는 수집 데이터에 포함되어 암호화됩니다. 공개 HTML이나 가상 미리보기에 개인 시트 주소를 넣지 않습니다. 이전 수집본에서는 새 소득 필드와 링크가 없어 자료 없음/링크 숨김으로 표시하다가 다음 정상 수집 후 나타납니다.
- 없거나 실패한 수집은 원래 데이터 상태 정책을 따릅니다. 시트는 수정하지 않습니다.

검사: Node 회귀 테스트 14개, 빌드 일치 검사. Python 수집 필드 검사는 GitHub Actions에서 수행합니다. 공개 미리보기에는 실제 재무정보를 넣지 않습니다.
