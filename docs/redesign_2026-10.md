# 분당부부 대시보드 개선 — 2026-10-23

선택한 디자인: 차분한 프리미엄. 아이보리, 딥네이비, 절제된 골드. 기존 여행 이미지와 GitHub Pages 배포 구조를 유지한다.

## 구현

- 오늘 / 우리 돈 / 은퇴 계획 / 다음 삶의 네 영역. 기존 상세 탭과 검색 유지.
- 오늘 요약: 확정 기록 대비 순자산 변화, 유동성·연금성 투자자산, FIRE 목표 진행, 확인할 항목.
- 항목별 마지막 정상 수집 시각과 오류·일별 기록·지연 상태를 보여주는 데이터 패널.
- 부채 목록의 정상적인 빈 결과를 수집 실패와 구분. 0원 부채를 순자산에 반영.
- 기존 오류 반환 규약을 고려해 빈 객체는 실패로 취급. 목록의 빈 배열은 정상 결과다. 부채 리더는 strict 옵션에서 수집 실패를 예외로 반환한다.
- 비밀번호는 기본 탭 세션 보관. 명시적으로 선택한 기기만 지속 저장. 잠금 시 저장정보 삭제.
- 화면을 계속 켜둔 경우에도 5분 주기로 발행본 확인. 수집 요청을 직접 실행하는 기능과 구분.
- 모바일 후보집 카드. 관리비·대출·전입 조건은 원문에서 별도로 확인하도록 표시.
- 은퇴 가정 계산기: 기간·추가저축·수익률·월 지출에 따른 유동성/연금성 자산을 분리. 원본 시트는 읽기 전용이다.
- 시트의 미래 전망 출발점을 현재 평가액으로 덮어씌우지 않는다. 기록과 현재 평가 차이를 설명한다.
- 반복 렌더 시 차트·시뮬레이션·매물·리뷰 이벤트 중복 방지. 빈 투자내역 후 정상 복귀 가능.
- live/update 워크플로 제한시간, 별도 읽기 전용 품질 검사 워크플로 추가.

## 검증

- Node 회귀 테스트 13개 통과: 시간대, 데이터 상태, 빈 부채/뉴스 병합, 가정 계산, 로그인 보관과 잠금, 전체 JS 구문.
- 소스와 docs/index.html 빌드 결과 일치.
- 샘플 미리보기 내 모든 인라인 스크립트 구문 검증.
- 로컬 Python 인터프리터 실행 불가. Python 구문 검사 및 블록 캐시/시장시간 테스트를 GitHub Actions에 구성했다. 원격 실행 결과를 별도로 확인해야 한다.
- 브라우저의 로컬 HTTP 접속과 file URL 열기가 제한돼 실제 렌더링·모바일·다크모드·키보드 조작은 수동 검증이 필요하다. 실행 화면 QA를 통과한 것으로 간주하지 않는다.

## 미리보기

`node tools/write-preview.mjs`로 `docs/preview.local.html`을 만든다. 이미지/서체를 포함하는 독립 파일이며 모든 화면 수치는 샘플이다. Git에서 제외해 프로덕션에 배포하지 않는다.

`node tools/preview.mjs`는 로컬 HTTP 미리보기다. 실제 암호화 재무 파일은 제공하지 않으며 public 이미지 경로만 제공한다.

## 배포 전 확인

로그인/잠금, 375·768·1440px 화면, 라이트/다크, 아홉 상세 탭, 검색/키보드, 새로고침 반복, 정상 빈 결과와 수집 실패, 실제 시트의 읽기 경로를 확인한다. 실제 재무정보를 테스트 fixture나 저장소에 복사하지 않는다.

## 이후 검토할 기능

공용 체크리스트의 기기 간 동기화에는 인증된 쓰기 경로를 설계해야 한다. 자산 증감의 원인 분석에는 입출금/거래 기록이 필요하다. 현재 데이터만으로 저축과 수익을 임의 분리하지 않는다. 세금·건보료 가정의 연도별 원자료 재검토는 별도 작업으로 남아 있다.

## 접속 가능한 샘플 미리보기

https://kimwoss.github.io/asset-dashboard/preview-redesign/

`node tools/write-preview.mjs --web`로 `review/preview-web.html`을 재생성한다. 이 파일은 가상 fixture만 사용하고 실제 암호화 재무 데이터를 읽지 않는다. 공개 미리보기는 수동 갱신이므로 배포 이후 수집 시각이 오래된 상태로 표시될 수 있다.
